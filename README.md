Create your 3-face-flashcards in `.csv` file

Some notes you need to know before use: <br><br>
	- This website only support editing <strong>ONE SET AT A TIME</strong>. So make sure you <strong>Export your csv file</strong> before editing your new set<br>
	<em>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;*Tip: If you want to have several flashcard sets, export the set and move it to a dedicated folder (Make sure you remember where it is). When you want to edit, just import that set in and you're good to go 👍</em><br><br>
	- Importing a .csv file will ADD UP to the set card. If you want to import a new set of cards, <strong>Clear all</strong> before importing or it will add up to current set instead<br><br>
	- <strong>Save Button</strong> is for when you want to save current card. If you want to add cards, use <strong>Add Card Button</strong> instead<br><br>
	- <strong>NEVER</strong> use <strong>Save</strong> after <strong>Clear Fields</strong> (This makes it replace the current card)<br><br>
	- !! <strong>Add New Card</strong> does NOT automatically add a blank card to save. Instead, <strong>Clear Fields</strong> and enter the content, then <strong>Add New Card</strong><br><br>
	- <strong>NOW YOU CAN</strong> use <strong>","</strong> in your flashcards - it will <em>NOT</em> be buggy and I <strong>FIXED THAT!!! 🎉🔥</strong> <em>(I assume this thing nobody did lol)</em><br><br>
	<em>- This website currently does NOT support rearranging cards manually, but I might add it in the future</em><br><br>
