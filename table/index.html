Create your 3-face-flashcards in ".csv" file Some notes you need to know before use:

- This website only support editing ONE SET PER BROWSER AT A TIME. So make sure you Export your csv file before editing your new set
     *Tip: If you want to have several flashcard sets, export the set and move it to a dedicated folder (Make sure you remember where it is). When you want to edit, just import that set in and you're good to go 👍

- This website does NOT save your flashcard to the cloud server (I don't even have one lol). It uses local storage of your browser to load out your cards. Consider saving it locally and upload to somewhere safe (Like a USB or Google Drive or simply your storage) - Importing a .csv file will ADD UP to the set card. If you want to import a new set of cards, Clear all before importing or it will add up to current set instead

- NOW YOU CAN use "," in your flashcards - it will NOT be buggy and I FIXED THAT!!!

*Key bindings:

Enter: Add new card

Arrows: Move between cells (Left/Right only moves when at the start/end of the cell)

Tab/Shift + Tab: Move between cells faster

Ctrl + Shift + Delete: Delete Selected row
