Create your 3-face-flashcards in ".csv" file Some notes you need to know before use:

- This website only support editing ONE SET AT A TIME. So make sure you Export your csv file before editing your new set
     *Tip: If you want to have several flashcard sets, export the set and move it to a dedicated folder (Make sure you remember where it is). When you want to edit, just import that set in and you're good to go 👍

- Importing a .csv file will ADD UP to the set card. If you want to import a new set of cards, Clear all before importing or it will add up to current set instead

- Save Button is for when you want to save current card. If you want to add cards, use Add Card Button instead

- NEVER use Save after Clear Fields (This makes it replace the current card)

- !! Add New Card does NOT automatically add a blank card to save. Instead, Clear Fields and enter the content, then Add New Card

- NOW YOU CAN use "," in your flashcards - it will NOT be buggy and I FIXED THAT!!!

- Contact me on Facebook: Panana Astley

*Key bindings:

Enter: Add new card

Arrows: Move between cells (Left/Right only moves when at the start/end of the cell)
